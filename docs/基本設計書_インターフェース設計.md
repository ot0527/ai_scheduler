## Edge Function 一覧

いずれも Supabase Edge Function として提供する。
呼び出し時は JWT による認証を必須とする。

| 名称 | HTTP | 利用する大機能 | 概要 |
| --- | --- | --- | --- |
| `goal-decompose` | POST | AI 支援 | 目標を AI 分解し、プレビューを返す |
| `goal-approve-decompose` | POST | AI 支援 | 分解結果を検証し DB に保存する |
| `ai-settings` | GET / POST | AI 支援 | AI 設定の取得・接続テスト・保存 |
| `budget-calculate` | POST | 計画立案 | 週次時間予算を計算する |
| `schedule-generate` | POST | 計画立案 | 日次仮スケジュールを生成する |
| `schedule-reschedule-minor` | POST | リスケ | 未完了ブロックを再配置する |
| `reschedule-major` | POST | リスケ | 大規模リスケの調整案を AI が返す |
| `ai-chat` | POST | AI 支援 | AI 相談の応答を返す |
| `export-data` | GET | 設定・データ権 | 全ユーザーデータを JSON で返す |
| `delete-account` | POST | 設定・データ権 | アカウントおよび全データを削除する |

## Edge Function 概要

### goal-decompose

目標 ID を受け取り、AI による分解結果（構成要素・作業ブロック）をプレビューとして返す。
分解結果はこの時点では DB に保存しない。
1 日 5 回まで。

### goal-approve-decompose

ユーザーが承認した分解結果を再検証し、DB に保存する。
保存後、目標を有効化する。

### ai-settings

GET: 現在の AI 設定（API キーは末尾 4 桁のみ）を返す。  
POST: プロバイダ・モデル・API キー・口調を受け取り、接続テスト後に Vault へ保存する。

### budget-calculate

基準日（省略時は当日）を受け取り、週次時間予算および警告を計算する。
結果を DB に保存する。

### schedule-generate

対象日を受け取り、空き時間への作業ブロック配置を行う。
仮スケジュールとして DB に保存する。

### schedule-reschedule-minor

未完了ブロックを受け取り、翌日〜7 日後の空き時間へ再配置する。
再配置結果は仮スケジュールとして保存する。

### reschedule-major

遅延目標の状況を AI に渡し、週次予算の調整プレビューを返す。
DB 更新はユーザー承認後にクライアントが行う。
1 日 3 回まで。

### ai-chat

会話履歴および目標・予算・予定のコンテキストを受け取り、AI 応答を返す。
1 日 20 回まで。月間トークン上限を設定している場合は enforcement する。

### export-data

認証ユーザーの全データを JSON 形式で返す。

### delete-account

ユーザーの確認後、Vault キー・全データ・認証ユーザーを削除する。

## クライアント直接アクセス（PostgREST）

以下の操作は Edge Function を経由せず、Supabase Client から DB に直接アクセスする。

- 生活リズム・固定予定・基本設定の CRUD
- 目標の CRUD（AI 分解を除く）
- スケジュール承認（status 更新）
- 完了記録・振り返りの保存
- 通知設定の保存

いずれも RLS により本人データのみアクセス可能とする。

## 外部インターフェース

| 外部サービス | 用途 | アクセス経路 |
| --- | --- | --- |
| OpenAI API | 目標分解、大規模リスケ、AI 相談 | Edge Function（ユーザー API キー） |
| Google Gemini API | 同上 | Edge Function（ユーザー API キー） |
| Supabase Auth | ログイン・JWT 発行 | Client / Edge Function |
| Supabase Vault | API キーの暗号化保存 | Edge Function（RPC 経由） |

## DB RPC

Edge Function から利用するストアド関数。

| 名称 | 用途 |
| --- | --- |
| `store_user_api_key` | API キーを Vault に保存する |
| `get_api_key_by_ref` | Vault から API キーを復号する |
| `purge_old_ai_request_logs` | 90 日超の AI ログを削除する（service_role） |

## エラー方針

| HTTP ステータス | 意味 | 画面での扱い |
| --- | --- | --- |
| 400 | 入力不正、API キー未設定 | エラーメッセージを表示 |
| 401 | 認証失敗 | セッションエラーとして扱う |
| 404 | 対象データ不在 | 画面内にエラーを表示 |
| 429 | レート制限・トークン上限 | 上限到達メッセージを表示 |
| 500 | サーバーまたは AI 障害 | エラー本文を抽出して表示 |
